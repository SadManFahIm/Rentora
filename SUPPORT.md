# Support

Need help? Pick the channel that matches the kind of question you have.

## Documentation first

- [README](README.md) — overview, features, roadmap, screenshots
- [CONTRIBUTING](CONTRIBUTING.md) — local setup, workflow, coding standards
- [docs/](docs/) — phase specs, architecture, API reference, security notes

## Bugs & feature requests

- Open an issue using the [issue templates](.github/ISSUE_TEMPLATE/) —
  include the steps to reproduce (bug) or the problem you are solving
  (feature), the environment, and any relevant logs.
- UI changes should include screenshots.

## Security vulnerabilities

**Do not open a public issue for security problems.** Report privately per the
policy in [SECURITY.md](SECURITY.md).

## Scope of support

This is a product repository maintained by NeoNexor Software. Best-effort
community support is provided for:

- Setting up the project locally (`make setup`)
- Developer workflow questions (`make check`)
- Understanding the API and phase documentation

Not in scope:

- Customizations for your own business logic
- Deployment outside the defined production stack (Phase 8)
